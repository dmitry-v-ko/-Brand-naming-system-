# Claude skill download

[Download brand-naming.zip](https://github.com/dmitry-v-ko/-Brand-naming-system-/raw/refs/heads/main/downloads/brand-naming.zip) and follow the [Claude installation guide](../docs/INSTALL_CLAUDE.md).

The archive contains one `brand-naming/` folder with the portable entry-point `SKILL.md`, the conductor, eighteen active methods, their source documents and the other Markdown reference files. It excludes Git metadata, download artifacts, credentials and real naming-session records. The entry-point adapter does not add a nineteenth methodology.

This is a distribution snapshot of the canonical files in this repository. A `PACKAGE_CONTENTS.json` inside the ZIP records each included source path and SHA-256 hash. When the entry point or bundled documents change, regenerate the archive from current sources and verify every recorded hash; do not treat an older ZIP as automatically updated. No runtime or installation script is included.
