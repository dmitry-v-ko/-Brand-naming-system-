## Findings and repairs

1. **Local retention was too permissive for combined presentation.** Some locally retained forms had an acknowledged conflict with tone or intended reading. The conductor now makes a separate suitability decision against the shared brief. There is no obligation to recommend one name per method. Original worker assessments remain intact.
2. **Near variants inflated apparent breadth.** Related sound strings and historical spellings now share a presentation direction with one representative; exact candidate IDs and separate provenance remain in the pool.
3. **Spoken assembly and written reading were conflated.** A valid two-syllable construction was retained despite a strong predicted one-syllable reading. The syllable-recombination selection rule now explicitly separates those axes and parks unsuitable spellings without relabeling valid construction as an operator failure.
4. **Result identity depended on the trial wrapper.** The trial supplied run IDs in addition to method/revision; the library result contract now requires that identity explicitly and rejects mismatched packets before coverage reconciliation. The host's worker reference belongs in the dispatch ledger. No actual cross-run packet mix-up occurred in the baseline.
5. **Resume records lagged behind execution.** The independent baseline audit found initial-only exploration logs while the pool was already complete. Completion now explicitly requires a compact update of coverage, combined pool, conductor decisions, active/parked directions and next options. Shortlists remain governed by actual user consent.

6. **Parked candidates were missing from the accounting formula.** The first post-fix review caught a retained/parked/rejected split that the old binary formula could not represent. The session contract and exploration template now explicitly count all three, label the assessment layer and preserve prior judgments.

The small corpus exercise had four saved text samples, token totals 32 and 30, and fourteen term rows. The conductor and independent reviewer recomputed the arithmetic. Uniform singleton differences provided no useful frequency ranking; the worker had already labeled the comparison exploratory and stated its limitations, so no operator rewrite was warranted. A few workers abbreviated common comparison contexts; the conductor reapplied the complete shared contexts to final representatives.
