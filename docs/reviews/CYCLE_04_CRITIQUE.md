This is an execution error, not evidence that all literary transfer is invalid. It demonstrates that a plausible pattern card and correct concatenation can conceal a false hybrid claim.

Require the selected realization skill to be read before generation; carry its eligibility tests into the card/ledger. Expand the author P01 card enough to show input types, variable slots, exclusions, source test and child constraints in one usable artifact. Do not force the observed author token to obey an invented historical letter recipe. Acceptance: a separate reader transfers a pattern to a new brief, checks every declared child construction, distinguishes invalid maps from valid-but-unsuitable names, and obtains at least one retained conforming option or honestly parks the branch. Preserve the original failed probe; a repaired new run must not rewrite it.

**P1 — Make the ordinary-session path lighter and internally consistent.** AGENTS prescribes 3–6 methods with 2–3 previews, then 6–12 universes for external vocabulary. `lexical-research` instead permits two distant universes and the full menu if requested; other local procedures use small defaults. This can require many choices before a useful research branch. Direct/delegated instructions already bypass menus successfully, as the new trial shows. Make that efficient behavior available for an ordinary sufficiently specified brief without inventing user delegation.

Specify a short path: record necessary assumptions, show a few contrasting directions and a recommendation, then expand menus when uncertainty or the user calls for breadth. Keep batch sizes and grids private defaults. Clarify that IDs, status fields, exact cut maps, source ledgers and reconciliation belong in internal records by default. The naming-facing response normally needs names, a brief reason, a proposed reading where relevant, one concrete drawback and concise evidence status; detailed tables and research should remain available on demand. Preserve source/uncertainty honesty even in the short presentation. Keep checkpoints and hash tests explicitly audit-only. Do not remove exact consent, stable lineage, failed-source status or memory reconciliation to achieve brevity.

Tradeoff: shorter menus expose less breadth upfront; preserve parked possibilities and allow a full menu immediately when requested. A compact internal ledger retains traceability while reducing repeated prose. Acceptance: a new common brief reaches meaningful contrasting names in a short response without mandatory broad universe enumeration or provenance-table flooding; a research-heavy request can still obtain complete sources/maps; a resumed session preserves exact favorites and unknown preferences. No timing study or software UI is required.
