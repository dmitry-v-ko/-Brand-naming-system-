# Prefix Attachment

- id: `prefix-attachment`
- family: structural construction
- status: draft
- implementation: complete editorial procedure; independent acceptance pending
- requires: research-optional
- outputs: candidate ledger, method artifact, feedback/state delta

## Mechanism and boundary

Attach an explicit initial operator to an unchanged stem. Keep semantic prefixes separate from invented entry sounds. The first segment frames direction or stance; `suffix-attachment` instead changes the ending/role. Clipping a stem is a separate earlier operation.

## Use, avoid and inputs

Use when a stable concept needs a distinct stance: again, together, beyond, before. Avoid when every candidate is a fashionable prefix costume, or the prefix implies a capability the product lacks.

Required: 2–3 intact stems and one desired stance. Default prefix modes: repetition `re-`, relation `co-`, beyond `ultra-`; these are editorial working glosses, not historical claims. Optional: word-boundary spelling, alternative stance or invented initial syllable.

## Procedure

1. Hold the stem bank fixed. Build columns for three prefix functions, stating the contribution before creating forms.
2. Write a 3×3 matrix; attach without silent deletion or spelling normalization. If a conventional spelling change is desired, record a later adaptation.
3. Reject cells whose combined promise misrepresents the offer. Compare at least two entry rhythms with the same stem to isolate the prefix's effect.
4. Read “___ helps you …” with identical context; mark repetitive consonants and competing readings. Show three to six forms with the prefix's semantic contribution.
5. If none supports positioning, change the stance or stem bank rather than accumulate more prefixes.

## Selection and recovery

Select for meaningful stance, an intact stem and pronounceable initial boundary. Repetition should fit actual repeat use; “ultra” should not imply measured superiority without basis. Repair a decorative prefix by switching its function; repair a cluster by choosing another intact stem. Agent glosses need no invented historical etymology.

## Research and evidence

Sources optional for supplied English parts. If a specialist prefix sense matters, search exact prefix + reputable dictionary, open the relevant sense and limit the gloss. If unavailable, label the prefix function as a proposed naming association, not verified etymology. For foreign combining forms route first to `cross-language-mining`.

## Candidate record and interaction

Use the [session protocol](../../docs/SESSION_PROTOCOL.md) and [source contract](../../docs/SOURCES_AND_RESEARCH.md). Every internal candidate record has stable branch/candidate IDs; English spelling; proposed pronunciation/stress where uncertain; exact lineage; separate `form` and `evidence`; source IDs or `none`; useful association and main drawback. Ordinary responses show 2–3 contrasts with a brief reason, relevant reading/risk and terse evidence status; IDs and detailed tables stay in the exploration log or session-owned research notes unless requested. Batch/grid sizes are private defaults, not user-facing quotas. Do not put real sessions in this library.

For a sufficiently specified brief, proceed with two or three useful contrasts and a recommendation; no separate preview gate is required. Expand menus when requested or real uncertainty changes direction. Record inferred choices as agent judgments, never as user delegation. Ask which property to preserve, not merely which name is “best.” After feedback record the actual words, changed constraints, rejected/parked paths and next options. Praise does not save a name. Add only explicit selections; repeated selection updates the same candidate. A six-name batch is a pause for navigation, never an automatic export.

## Ordered combinations

`lexical-research` → `prefix-attachment` retains verified stems. `clipping` → `prefix-attachment` shortens first, then adds; record both steps. `prefix-attachment` → `intact-word-compounding` adds a second word only in a child branch.
