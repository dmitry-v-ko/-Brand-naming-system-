# Intact Word Compounding

- id: `intact-word-compounding`
- family: structural construction
- status: draft
- implementation: complete editorial procedure; independent acceptance pending
- requires: research-optional
- outputs: candidate ledger, method artifact, feedback/state delta

## Mechanism and boundary

Join two complete words, preserving their letters and order within each word. The primary artifact is a relationship matrix. Unlike `fragment-blending`, nothing is deleted; unlike `metaphor-mining`, the operation is assembly, even when an ingredient is metaphorical.

## Use, avoid and inputs

Use when two ideas must remain legible, when the brand needs a short explanatory story, or for an accessible English-facing name. Avoid when the brief demands one abstract two-syllable word or either word would imply an unsupported product feature.

Required: one identity anchor and one complementary role (benefit, action, object or context), inferred from the brief. Default: 3 anchors × 3 partners; maximum 12 letters excluding spaces is a soft preference. Optional: permitted open/closed spelling and head-noun preference. Supplied vocabulary needs no invented dictionary citation.

## Procedure

1. Rewrite the promise as “X helps Y do Z.” Extract three anchors and three partners in separate columns; exclude three obvious category clichés.
2. Pair all nine cells. For each write a relationship: object doing action, place for activity, or modifier of head. Reject cells requiring a paragraph to connect.
3. Reverse the order for the three strongest cells; note how the head noun changes the implied offer. Preserve both words intact, even at repeated-letter joins.
4. Produce one practical, one unexpected and one gentle cluster, two forms each. Compare open and closed spelling without changing lexical units.
5. Read an identical introduction for each: “We use ___ to …”. Mark cumbersome boundaries and misleading category cues. Return three to six candidates with relationships.

## Selection and recovery

Prefer a reconstructible relationship, speakable boundary and a useful difference between clusters. An unexpected pairing is not automatically better. If all cells are literal, replace the partner bank, not random letters. If all are obscure, keep a familiar anchor and weaken the surprise. If length fails, change ingredients; cutting letters is a separate `clipping` branch.

## Research and evidence

For ordinary supplied English words, label evidence not applicable to research. When meaning is technical, use `lexical-research` first: query exact headword + reference domain, inspect definition, retain source. If unavailable, use a plain-language supplied alternative or mark the semantic claim unverified.

Keep intermediate tables in the exploration log or session-owned research notes. Do not put real sessions in this library.

Show two or three contrasting previews before expanding, unless the user already delegated or specified the operation. Ask which property to preserve, not merely which name is “best.” After feedback record the actual words, changed constraints, rejected/parked paths and next options. Praise does not save a name. Add only explicit selections; repeated selection updates the same candidate. A six-name batch is a pause for navigation, never an automatic export.

## Ordered combinations

`lexical-research` → `intact-word-compounding`: verified terms become intact ingredients. `metaphor-mining` → `intact-word-compounding`: select transferable object, then pair it with a benefit. `intact-word-compounding` → `clipping` is a new child branch and changes the form/lineage.

## Complete synthetic worked trace

All brand briefs, candidate judgments and user turns below are fixtures, not consumer findings. Source facts are separately identified. IDs are local to this trace.

Brief: a welcoming workshop booking service; clear yet imaginative. B01 previews: practical **Workshop Window**, gentle **Open Nest**, unexpected **Bench Lantern** (all invented / not applicable). User fixture: “Explore the workshop image, without sounding like a lighting shop.”

Ingredient ledger: anchors bench / workshop / craft; partners window / nest / lantern. All are supplied English fixture vocabulary, source none. Matrix:

| Anchor | window | nest | lantern |
|---|---|---|---|
| bench | Bench Window: access to making | Bench Nest: cozy place to make | Bench Lantern: guidance, lighting risk |
| workshop | Workshop Window: booking access, long | Workshop Nest: venue community | Workshop Lantern: literal lamp risk |
| craft | Craft Window: showcase, retail risk | Craft Nest: community | Craft Lantern: guidance, generic craft category |

B01-C01 **Bench Window**, BENCH WIN-doh: `bench + window`, retains both; invented / not applicable. C02 **Bench Nest**, BENCH NEST: `bench + nest`; softer but consonant boundary /tʃn/ needs care. C03 **Bench Lantern**, BENCH LAN-tern: too much lighting association; reject for this brief. Reversal **Window Bench** reads as furniture rather than access; do not treat it as equivalent.

Repair: replace lantern with invitation vocabulary **Open Bench** (C04, OH-pən BENCH); both words intact, clearer availability story. User fixture: “Save Open Bench; Bench Nest feels childish.” State delta: favorites=[B01-C04]; rejected_direction=cozy/nest; active B01 REFINE; next_options=more open/invitation partners, explore lexical research, finish only on request. C01 remains unsaved; no silent pruning.
